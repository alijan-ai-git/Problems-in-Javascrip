# DSA Problems in JavaScript 🚀
A curated collection of **Data Structures & Algorithms problems and solutions** implemented in **vanilla JavaScript**. Built for practice, interview preparation, and strengthening problem-solving fundamentals.

## 🧠 What’s Inside
This repository contains a wide range of JavaScript problem files covering:
- **Search Algorithms:** Binary Search (iterative & recursive)  
- **Sorting Techniques:** Insertion Sort, Selection Sort, Descending Sort  
- **Data Structures:** Stack, Queue, Linked List, Graph, Set, Map  
- **Recursion Patterns:** Direct & Indirect Recursion  
- **String Manipulations:** Palindrome, Reverse Logic  
- **Array Operations:** Traversal, Merging, Push/Pop, Element Deletion  
- **Logic & Problem-Solving Exercises**

Each file implements one problem or concept using clear and focused code.
